# 핵심 암기노트 — 챕터별 외울 것 + 주요 이론

> 시험·실무 직전 펴보는 압축본. **"왜(이론)" 한 줄 + "외울 것(공식·숫자·규칙)"** 으로 정리.
> 예제: CE=에어컨(72개월·2191일) / MX=갤럭시탭(48개월·1461일)

---

## 📌 0. 전체 뼈대 (먼저 머리에)
- **세 파일 사슬**: 프라이싱(구독료 생성) → 손익(금융리스 인식) → 시뮬레이터(할인·이벤트 적용)
- **모든 시트 = 리스 상각표(엔진) + 이벤트 정산**
- **할인의 두 얼굴**: 매출차감(포인트류=당월) / 에누리(선납·단품·결합=기간 스프레드)

## 1️⃣ 엔진 — 리스 상각표

**핵심이론**: 구독 = 제품을 할부(금융리스)로 판 것. 리스채권=제품값, 매월 구독료=원금+이자. **할인·선납으로 받을 돈이 바뀌면 내재이자율(IRR)을 다시 푼다.**

**외울 것**
```
리스채권 = MIN(제품v−, PV(현할차/12, N, −순수월액))  (−선납금)
순수구독료 = 총구독료 − 케어 − 보증  (−선납 −할인)
리스료(월) = 순수구독료 / N
월이자율 F3 = RATE(N, −리스료, 리스채권)   ← IRR / 연이자율 = ×12
기말 = 기초 + 이자 − 리스료   (만기 0)
```
**첫날/중간/막달 (회사 방식 — 암기)**
```
첫날(27/31): 리스료=−(총·케어·보증 각 일할 반올림)=실제청구액
            이자=ROUND(−E + (기초×F3 − H2)×27/31, 0)
중간:        리스료=−H2(고정) / 이자=ROUND(기초×F3,0)
막달:        리스료=−H2−첫달치(남은 4/31) / 이자=plug(잔액 0)
```
**실측 숫자**: 베이스 채권 4,809,091·연 15.63% │ 선납후 4,065,091·18.17% │ 선납+단품+결합 4,065,091·9.91%

## 2️⃣ 할인 6단계 + 정상만기 청구

**핵심이론**: 총액×율을 바로 나누면 끝자리가 지저분 → **월로 먼저 반올림 후 ×기간**(단수조정). 케어·보증은 할인 0.

**외울 것**
```
할인 6단계: ①기준×율 → ②÷1.1 → ③ROUND(②/N,−2) → ④×1.1 → ⑤③×N → ⑥구독료−월할인금
청구일 = EOMONTH(결제월,0)+15  (익월 15일)
1회차 일할 = ROUNDDOWN((총구독료/N)×사용일/그달일, −2)
제품 = 구독료 − 케어 − 보증  (잔여)
```
- **선납금(목돈) ≠ 선납할인(4%)** — 별개 라인
- **CE↔MX 차이 딱 2개**: ⑴파손보험 비과세 → v+=(제품+보증+케어)×1.1+파손 ⑵할인기준=v+−파손보험

## 3️⃣ 중도해지 (정산 5종)

**핵심이론**: 제품판정일 기준. **현금 정산이라 실제 거래액(반올림) 기준.**

**외울 것**
```
① 위약금   = 총구독료(v+) × 잔여비율 × 20%   (비과세, v+ 그대로)
② 사용분   = 반영 월구독료 × 당월경과/그달일
③ 할인회수 = 받은 할인 × 경과비율
④ 선납환불 = −선납금 × 잔여비율   (회사→고객)
⑤ 등록비   = 등록비 × 경과비율
경과비율 = Σ경과일/2191,  잔여비율 = (2191−Σ경과일)/2191
```
🧠 **할인회수=경과 / 선납환불=잔여 (방향 반대! 헬스장 환불)**

## 4️⃣ 중도완납 + 연체 강제해지

**중도완납** (위약금 X, 남은 값 일시 완납)
```
완납금 = ROUNDDOWN(매출인식기준구독료 × 미사용일/전체일, −2)  ← 케어·보증 제외
사용분 = 반영월구독료 × 당월경과/그달 │ 선납차감 = −선납금 × 잔여
```
**연체 강제해지**
```
연체이자 = 밀린구독료 × 6% × (연체일/365)   ← 1·2·3회 각각 누적
3개월(3회) 초과 → 강제해지 (계약중지 = 마지막청구 + 2일)
사용분 = 밀린 미납분 합산 + 당월일할 │ 나머지는 중도해지와 동일 골격
```

## 5️⃣ 할인원복 + AS보상

**할인원복** (결합 깨짐)
```
결합(묶음) 조건 깨짐 → 다품목 할인 회수(경과비율)
구독료 원복 = 익익월부터 (예: 21회차)   ← "출발한 청구 못 멈춰 두 박자 뒤"
```
**AS 미사용 보상** (회사→고객)
```
보상금 = ROUNDUP(기본 월구독료 × 미사용일/그달일, −2)
기본구독료 기준(할인 무관), 고객 유리하게 ROUNDUP
```

## 6️⃣ 회계 종합 (가장 자주 질문)

**핵심이론**
- **에누리 메커니즘**: 매출인식기준 구독료↓ → 이자수익↓ → **구독기간 전체 스프레드**
- **매출차감(포인트류)**: 당월 손익 즉시
- **100원 내리면?**: 이자수익에서만 빠짐(기간 분산), 제품매출은 cap(MIN)이라 불변. *단, 아주 크게 내려 PV<제품값이면 제품매출도 타격(면제/반값)*
- **이론값 vs 실제값**: 이론=반올림 전 정확값 / 실제=반올림 후 청구·장부값
- **손익 vs 현금**: 이자수익(손익)=유효이자율(이론) / 중도해지(현금)=실거래액(반올림)
- 단수 반올림차는 immaterial → 순이익 동일, 분류만 다름(이자수익 vs 잡손익)

## 🎯 치트시트 (통째 암기)

**정산 비율·방향**
| 정산 | 비율 | 방향 |
|---|---|---|
| 위약금 | 잔여×20% | 고객→회사 |
| 사용분 | 당월경과/그달 | 고객→회사 |
| 할인회수 | **경과** | 고객→회사 |
| 선납환불 | **잔여** | 회사→고객(−) |
| 등록비 | 경과 | 고객→회사 |
| 완납금 | 미사용/전체 | 고객→회사 |
| AS보상 | 미사용일 | 회사→고객(−) |

**과세**: ×1.1 = 구독료·제품·케어·보증·등록비·사용분 / **비과세** = 파손보험·위약금·연체이자·분실/파손료
**단수**: 구독료·할인 = ROUNDDOWN(−2) / 위약금·연체 = −1(10원) / 고객환급(AS·선납) = ROUNDUP

**핵심 숫자**: 위약율 20% · 연체이자 6%·365 · 선납 30% · 할인 선납4%·단품5%·결합5% · 청구일 익월15일
