# Level 2 — 정산 심화 6시트 수식 이해

> 대상: 리스상각표(결합·A해지·월할) / 할인원복(익익월) / 연체강제해지(CE·MX) / AS보상(CE·MX)
> Level 1(엔진·할인·중도해지)을 안다는 전제. 여기선 **정산 이벤트 심화 + MX 파손보험**.

---

## ★★ 먼저: MX 파손보험의 정체 (이거 하나면 MX 다 풀림)

**파손보험은 비과세(부가세 0).** 그래서:
- **CE**: 구독료 전체가 과세 → v+ = 구독료 × 1.1 (단순)
- **MX**: 구독료 = **파손제외분(과세)** + **파손보험(비과세)** → **각각 따로** 계산 후 합침
```
[CE]  어떤 금액의 v+  = 금액 × 1.1
[MX]  어떤 금액의 v+  = (파손제외분 × 1.1)  +  파손보험   ← 파손은 ×1.1 안 함
```
이 한 줄이 **연체이자·AS보상·위약금·사용분** 전부에 똑같이 적용됩니다. MX 시트마다 `파손 제외 구독료`, `파손보험` 열이 따로 있는 이유예요.

---

## 1. 리스 상각표 (결합할인, A해지, 월할) = ★할인원복 상각표

**정체**: "할인 원복구독료 상각표". 결합(다품목)으로 묶어 할인받던 고객이 **중간에 A 제품을 해지** → 결합 조건이 깨져 → 남은 제품 **월구독료가 정상가로 원복**되는 상각표. (단순 결합 상각표가 아님!)

**2단 구조**
```
[1단] 할인 구간 (A해지 前): 리스료 = 할인 109,800, 할인 이자율로 상각
       (결합 반영: 순수 = 총−케어−보증−결합 = 6,588,000, 리스료 = 순수/60 = 109,800)

[2단] 원복 구간 (A해지 後):
       잔여채권   = 할인구간 해지회차의 기말채권 (F28을 이어받음)
       잔여기간   = 60 − 해지회차 (+ 부분월)
       원복 이자율 = RATE(잔여기간, −정상리스료 116,000, 잔여채권)   ← ★IRR 재계산
       정상 리스료 116,000 으로 잔여기간 상각 → 만기 0
```
**핵심**: 원복 = **해지 시점 채권 잔액을 그대로 이어받아, 정상 리스료(116,000)로 잔여기간 IRR을 다시 풀어** 상각. Level 1 엔진의 "받을 돈 바뀌면 IRR 재계산"이 **계약 중간**에 일어나는 케이스다. 리스료가 109,800 → 116,000 으로 점프.

**"월할"**: 1회차·원복 시점의 일할 처리 대안 컬럼(일할 로직 변경 대비).
**"A해지"**: 묶음 중 **A 제품을 해지**하는 것 = 원복의 트리거.
> 한 줄: **A제품 해지 → 정상가 원복 → 잔여채권 이어받아 정상리스료로 IRR 재계산.** 아래 §2 할인원복(익익월)의 *상각표 버전*.

## 2. 할인원복 (선납, 선납할인, 결합) — 익익월

**정체**: 묶음(다품목=결합) 조건이 깨지면 **다품목 할인 회수 + 익익월부터 정상가 원복**.

**3단 구독료** (열 블록)
```
기본 → 선납+선납할인+다품목 할인 적용 → (변경) 다품목 원복, 선납·선납할인은 유지
구독료 원복 = 21회차부터 (익익월: 깨진 달의 다다음 달)
```
**원복 정산** (결합해지일 Z, 경과일 AA)
```
사용분 청구 AB = 결합 적용분 (R24, 다품목 할인 받던 구독료)
할인금 회수 AC = 받은 다품목 할인 × 경과비율
```
**원복 후 또 중도해지** (제품판정일 AD, 경과일 AE)
```
위약금 AF + 사용분 AG + 할인금회수 AH + 선납잔액환불 AI   ← Level 1 중도해지 골격 그대로
```
> 한 줄: **결합 깨짐 → 다품목 할인만 경과분 회수 → 익익월 정상가**. 이후 해지는 일반 중도해지.

## 3. 연체미납 강제해지 (CE)

**정체**: 안 내면 연체이자 붙고, 3개월(3회) 초과 시 강제해지.

```
연체이자(1회분) = ROUNDDOWN(밀린구독료 × 1.1 × 6% × (연체일수)/365, −1)
  · 연체일수 = (다음 청구일 − 이번 청구일 − 1)
  · 1·2·3회분이 각각 따로 누적 → 누적 연체이자 = SUM
구독료(연체료)청구 = 정상구독료 + 누적 연체이자

[강제해지] 계약중지일 = 마지막 청구일 + 2일
 위약금 = 총구독료v+ × 잔여비율 × 20%
 사용분 = Σ밀린 미납분 + 당월 일할
 할인회수 = 할인 × 경과비율
 연체이자 = 누적분
 선납환불 = −선납금 × 잔여비율
 등록비 = 경과비율
```

## 4. 연체미납 강제해지 (MX) — ★파손 차이

CE와 **딱 한 군데** 다름: **연체이자 base가 파손 분리**.
```
[CE] 연체이자 = (구독료 × 1.1) × 6% × 일수/365
[MX] 연체이자 = (파손제외구독료 × 1.1 + 파손보험) × 6% × 일수/365
                 └── 과세분만 ×1.1 ──┘   └ 비과세 그대로 ┘
실측: Y24 = ROUNDDOWN((Q21*1.1 + U21)*6%*(I24−I21−1)/365, −1)
       Q21=파손제외 구독료, U21=파손보험
구독료청구 R = 파손제외(Q) − 케어 − 보증 = 제품
```
나머지(위약금·사용분·선납환불 등)는 CE와 동일 구조 (위약금도 파손 제외한 v+ 기준).

## 5. AS 미사용 기간 보상 (CE)

**정체**: AS를 약속만큼 못 줬으면 고객에게 환급. **기본구독료 기준, ROUNDUP**(고객 유리).
```
경과일 S = 종료 − AS시작 + 1
미사용기간분 T = ROUNDUP(기본 월구독료(J) × S/그달일수, −2)
최종 보상금 V = T
검증 X = ROUNDUP(총구독료v− × Σ미사용일/전체일, −2)
```

---

## 6. AS 미사용 기간 보상 (MX) — ★파손 차이

CE는 기본구독료 한 덩이로 보상. MX는 **과세분 + 파손 분리** 후 합산.
```
과세분 보상 AC = ROUNDUP((매출인식기준/전체일 ÷ 1.1) × 경과/그달, −2)   ← ÷1.1
파손   보상 AH = ROUNDUP((파손/전체일) × 경과/그달, −2)                 ← 비과세 그대로
최종 보상 = AC + AH (+ 케어·보증 분해분)
```
> 즉 CE는 "기본구독료 일할" 한 방, MX는 "과세분(÷1.1) + 파손(그대로)" 쪼개서 합침.

## 한눈 요약 — Level 2

| 시트 | 핵심 | 새 개념 |
|---|---|---|
| 상각표(결합·A해지·월할) | A제품 해지→정상가 원복, 잔여채권 이어받아 정상리스료 상각 | **기간 중간 IRR 재계산** |
| 할인원복(익익월) | 결합 깨짐→다품목 회수→익익월 정상가 | **익익월·다품목 회수** |
| 연체 강제해지 CE | 연체이자 누적, 3회 초과 강제 | **연체이자(6%·365)·계약중지** |
| 연체 강제해지 MX | 〃 + **연체이자 base 파손분리** | **MX 파손** |
| AS보상 CE | 기본구독료×미사용일 ROUNDUP | **미사용 보상** |
| AS보상 MX | 〃 + **과세분(÷1.1)+파손 분리** | **MX 파손** |

**관통 원리**: ① 정산은 항상 "경과/잔여 비율 × 실거래액" ② **MX는 파손보험 비과세라 항상 과세분(×1.1)과 파손(그대로)을 분리** ③ 고객에게 주는 건 ROUNDUP, 받는 건 ROUNDDOWN.
