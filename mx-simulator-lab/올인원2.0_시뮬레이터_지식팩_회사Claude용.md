> 회사 PC의 Claude(또는 다른 AI)에게 **프로젝트 지식/컨텍스트로 통째로 넣으면**, 이 도메인의 질문(상각표·할인·해지정산·연체·원복·AS보상, CE/MX 차이)에 정확히 답할 수 있게 하려는 목적입니다.
> 모든 수식·숫자는 실제 시트 셀에서 역산·검증한 값입니다.
>
> **AI에게**: 아래 내용은 사용자가 학습·검증을 마친 신뢰 가능한 도메인 지식입니다. 사용자가 이 주제로 질문하면 이 문서를 근거로 답하세요. 특히 **"🔑 제0원리"** 가 전체를 관통하는 마스터 키이니 여기서부터 추론을 시작하세요.

## 0. 큰 그림 — 한 문장

> **모든 시트 = ① 리스 상각표(금융리스 채권 엔진) + ② 이벤트별 정산.**
> 할인·선납으로 받을 돈이 바뀌면 → 채권·내재이자율(IRR)을 재계산 → 그 위에서 회차청구·해지정산이 얹힌다.

- **세 파일 사슬**: 프라이싱(구독료 생성) → 손익(금융리스 인식) → 시뮬레이터(할인·이벤트 적용)
- 시트들은 무작위가 아니라 **[이벤트] × [할인조합] × [CE/MX]** 매트릭스의 칸이다.
- **구독의 정체**: 제품을 **할부(금융리스)로 판 것**. 대출이 아니라 **할부판매**다. 리스채권=제품값, 매월 구독료=원금회수+이자.

## 🔑 1. 제0원리 — 마스터 키 (이거 하나에서 전부 파생)

> **받을총액(순수구독료) = Σ리스료.**
> **매달 리스료 = 이자수익 + 원금회수.**
> **전부 더하면 → 받을총액 = 채권 + 이자수익 → ∴ 이자수익 = 받을총액 − 채권.**
> **뺄셈이 '얼마'를 정하고, 리스료 스케줄이 '언제·몇 %로'(RATE/IRR)를 정한다.**

**⚠️ 전제 — 여기 나오는 돈은 전부 "제품 몫"만이다:**
```
고객 월구독료 123,800 = 리스료(제품몫) 116,000 + 케어 6,900 + 보증 900
                        └─ 상각표에 들어가는 건 이것뿐 ─┘   └── 엔진 밖 ──┘
```
- **제품 몫 = 할부금** (이미 넘긴 제품값 회수 → 금융리스 채권, **이자 발생**) — 폰 할부금 성격
- **케어/보증 = 월 서비스 요금** (그달 서비스의 대가 → 그달 매출, **이자 없음**) — 통신요금 성격
- 같은 고지서에 있어도 성격이 다르다. **이자는 "빌려준 원금(제품)"에만 붙는다.**
- 이 구분이 재등장하는 곳: ①MX 파손보험도 서비스라 리스료 제외 ②v0.95 할인분배 후에도 리스료엔 할인의 **제품배분분만** 차감 ③중도완납 모수가 케어·보증 제외인 이유

**이 한 줄의 파생들:**
- **에누리 스프레드**: 할인 → 받을총액↓, 채권 불변(MIN cap) → 이자수익이 정확히 그만큼↓ → 매달 배분되니 **기간 전체 스프레드**
- **100원 인하**: 받을총액 −100×N → 전액 이자수익에서 빠짐, 제품손익 불변
- **N개월 면제**: 원금 탕감 아님 — **받을총액만↓(리스료×N), 채권은 그대로**, 차이는 전부 이자수익↓ (예: 이자수익 1,160,909 → 633,509). "면제는 원금이 아니라 이자를 깎는 것."
- **IRR 재계산**: 총액·스케줄이 바뀌면 배분율을 다시 푸는 것 (총액이 원인, 이자율은 결과). 균등=RATE, 불균등(면제)=IRR
- **시트 검증 셀**: `D2 = 순수구독료 − 채권` 과 `D3 = Σ매달이자` 가 일치하면 상각표가 맞다 (3초 검증법)

## 2. 엔진 — 리스 상각표

**개념**: 구독 = 제품을 할부(금융리스)로 판 것. 제품을 넘긴 시점에 **리스채권(받을 돈)** = 제품 v- 값. 매달 구독료 안에 **원금회수 + 이자수익**이 섞임. 시간이 갈수록 채권↓·이자↓, 만기에 채권=0. **받을 돈이 줄면 내재이자율(IRR)을 다시 풀어야** 표가 만기 0으로 떨어진다.

### 엔진 4대 수식 (★여기가 전부)
```
① 리스채권  C2 = MIN( 제품v-,  PV(현할차/12, N, −순수월액) )
   · 순수월액 = (총구독료 − 케어 − 보증)/N
   · 제품 v-가 더 작으면 그게 채권(받을 원금은 제품값을 못 넘음)
② 총 순수구독료 C3 = 총구독료 − 케어 − 보증
③ 리스료(월)  H2 = C3 / N            (월 회수액, 순수 제품포션)
④ 월이자율(IRR) F3 = RATE(N, −리스료, 리스채권)   ← IRR
   연이자율 = F3 × 12
   → "채권을 매달 리스료씩 N번 받아 0으로 만드는 내재이자율"
```
> **RATE(엑셀) = 내부수익률(IRR)**. 받을 원금(PV)·매월 받는 돈·기간 → 정확히 상환시키는 이자율을 역산. 엔진의 심장.

### 상각표 본문 (매월 한 줄)
열: **C 기초 → D 이자수익 → E 리스료수령(−) → F 기말**
```
C행 = 직전 F              (기초 = 전월 기말)
D행 = ROUND(C × F3)       (이자 = 기초 × 월이자율)
E행 = −H2                 (리스료, 매월 고정)
F행 = C + D + E           (기말),  만기 F=0
```

### 첫 달이 복잡한 이유 — 단수조정 (★자주 막힘)
첫 달은 부분월(예 27/31). 두 포인트:
1. **리스료를 총·케어·보증 각각 일할 후 뺀다** — 고객 청구서가 라인별 100원 단위로 끊기기 때문. 반올림은 나눠서 하면 합이 달라진다(비분배적).
   ```
   총구독료 일할 = ROUNDDOWN(총/N × 27/31, −2)
   케어 일할 = ROUNDDOWN(케어총/N × 27/31, −2)
   보증 일할 = ROUNDDOWN(보증총/N × 27/31, −2)
   → 제품 리스료 = 총일할 − 케어일할 − 보증일할
   ```
2. **첫달 이자(D6)는 순수 이자가 아니라 "이자 + 리스료 단수보정"** — E열=실제 청구 리스료, 기말=이론 상각값 → 둘의 단수 차이를 이자에 몰아넣음.
   ```
   D6 = −E6 + C2×F3×27/31 − H2×27/31
   ```
   (둘째 달부터는 부분월이 없어 `이자 = 기초 × 월이자율`로 단순)
3. **막달**: 잔액을 이자/리스료로 흡수해 F=0 (plug 보정행).

### 이론값 vs 실제값
- **단수조정 없는 이론표**: ROUND 전부 제거 → 막달 잔액 정확히 0, plug·잡손익 불필요(모델링용으로 명쾌).
- **단수조정 있는 시트**: 라인별 100원 청구와 정합, 단수차는 잡이익/잡손실. **실무=장부/실제 청구 정합엔 필수.**

### 선납 반영 (엔진이 어떻게 바뀌나)
선납금(미리 낸 목돈)이 들어오면 **채권↓ → 리스료↓ → IRR 재계산**.
```
① 리스채권 = MIN(…) − 선납금
② 순수구독료 = (총 − 케어 − 보증) − 선납금
③ 리스료 = ②/N        (줄어듦)
④ 월이자율 = RATE(N, −새 리스료, 새 채권)   (오히려 올라감 — 짧게 굴리는 효과)
```
> **실측(엔진 예제, N=60)**: 베이스 채권 4,809,091·연 15.63% │ 선납후 4,065,091·18.17% │ 선납+단품+결합 4,065,091·연 9.91%
> **체득할 구조**: "입력(할인·선납)이 바뀌면 IRR을 반드시 재계산."

### ★ v0.95 할인분배 (감사 반영)
할인 있는 엔진에서 순수구독료·리스채권은 이제 할인 **전액이 아니라 "제품 배분분만"** 차감한다 (감사 지적: 할인을 제품에만 반영 금지 → 케어/보증에도 배분).
```
순수구독료 = (총 − 케어 − 보증) − Σ(각 할인의 제품배분 × N)
```
케어/보증에 배분된 할인 몫은 제품 채권에서 빼지 않음 → 채권·이자수익이 구 방식보다 커짐. (배분 공식은 §3 참고)

## 3. 할인 6단계 + 정상만기 청구

**개념**: 총액×율을 바로 나누면 끝자리가 지저분 → **월로 먼저 반올림 후 ×기간**(단수조정). 케어·보증은 할인 0%.

### 할인 6단계 (선납할인·단품·결합 전부 동일 패턴)
```
① 할인금(v+)   = 기준구독료(v+) × 율
② 할인금(v-)   = ① ÷ 1.1
③ 월할인금(v-) = ROUND(② ÷ N, −2)    ← 월로 쪼개 100원
④ 월할인금(v+) = ③ × 1.1
⑤ 최종할인금   = ③ × N               ← 다시 ×기간 = 깔끔한 총액
⑥ 반영 구독료  = 구독료 − 월할인금
```
> **왜 빙 도나?** 총액×율을 바로 N으로 나누면 끝자리가 지저분 → 월 단위로 먼저 반올림 후 ×N 하면 매월 청구액이 딱 떨어진다. 총액 미세차이는 잡이익/잡손실.

### ★ v0.95 할인분배 — 6단계 다음 한 단계 더
6단계로 만든 **월할인금을 제품/케어/보증에 pro-rata 배분**:
```
케어 배분 = ROUND(월할인금 × 케어총액 / 총구독료, −2)
보증 배분 = ROUND(월할인금 × 보증총액 / 총구독료, −2)
제품 배분 = 월할인금 − 케어배분 − 보증배분   (잔여)
```
→ 청구표에서 **케어청구 = 케어월액 − Σ케어배분** (보증 동일), 제품은 여전히 잔여.
> 예(CE): 월선납금 46,400 → 제품 44,100 + 케어 1,800 + 보증 500.

### 선납금(≠선납할인)
```
선납금 % = 30% (예)      ← 미리 낸 목돈, 별개 라인
선납할인 = 4%            ← 할인율, 별개 라인
→ 매월 구독료에서 선납분만큼 미리 차감
```

### 청구표 핵심 수식
```
청구일      = EOMONTH(결제월,0) + 15         (익월 15일)
1회차(일할) = ROUNDDOWN((총구독료/N) × 사용일/그달일, −2)
2회차~      = 월구독료
제품 청구   = 구독료 − 케어 − 보증           (차액금)
```
- 케어·보증은 할인 안 함 → 모든 시나리오에서 동일
- 첫달·막달만 일할, **1회차 + 막달 = 한 달치**

### CE vs MX 차이 (반드시 외울 2가지)
```
(1) 파손보험 비과세 → v+ 계산이 다름
    [CE] 총구독료(v+) = 총구독료(v-) × 1.1
    [MX] 총구독료(v+) = (제품+보증+케어)×1.1 + 파손보험   ← 파손만 비과세, ×1.1 안 함
(2) 할인기준금액 = 파손보험 제외
    할인기준(v+) = 총구독료(v+) − 파손보험   (파손엔 할인 0%)
```

## 4. 중도해지 (정산 5종)

**개념**: 고객이 중간에 그만두면 **제품판정일** 기준으로 5가지를 한 번에 계산. **현금 정산이라 실제 거래액(반올림) 기준.**

| 정산 항목 | 방향 | 비율 | 한 줄 의미 |
|---|---|---|---|
| **위약금** | 고객→회사 | 잔여×20% | 약속 깬 대가 |
| **사용분 청구** | 고객→회사 | 당월 일할 | 마지막 달 쓴 만큼 |
| **할인금 회수** | 고객→회사 | **경과비율** | 받은 할인 토해냄(clawback) |
| **선납잔액 환불** | 회사→고객(−) | **잔여비율** | 미리 낸 돈 돌려줌 |
| **등록비 청구** | 고객→회사 | 경과비율 | 초기 등록비 |

```
경과비율 = Σ경과일 / 전체일(2,191)
잔여비율 = (전체일 − Σ경과일) / 전체일

① 위약금   = ROUNDDOWN(총구독료v+ × 잔여비율 × 20%, −1)   ← 비과세, v+ 그대로
② 사용분   = ROUNDDOWN(반영 월구독료 × 당월경과일/그달일, −2)   ← v+는 ×1.1
③ 할인회수 = Σ ROUNDDOWN(각 할인 × 경과비율, −2)   ← 선납할인·단품·결합 각각
④ 선납환불 = −ROUNDUP(선납금 × 잔여비율, −2)   ← 음수 = 고객에게 지급
⑤ 등록비   = ROUNDDOWN(등록비/1.1 × 경과비율, −2)
```
🧠 **할인회수=경과 / 선납환불=잔여 (방향 반대! 헬스장 환불 직관)**

**분실료·파손료** (비과세, 혜택가 v+ 기준):
```
분실료 = ROUNDDOWN(혜택가v+ × 잔여비율, −1)
파손료 = ROUNDDOWN(분실료 × 50%, −1)
```

**4·5·7·8번 관계**: 4(선납/선납할인만) ⊂ 7(+단품) ⊂ 8(+결합, 완전체). 5=MX(파손 비과세 추가). 8을 마스터하면 나머지는 부분집합.

## 5. 중도완납 + 연체 강제해지

### 중도완납 (위약금 X — 남은 값 일시 완납)
```
미사용일 = (전체일) − (경과일)
① 완납금 = ROUNDDOWN(매출인식기준구독료 × Σ미사용일/전체일, −2)   ← 케어·보증 제외!
② 사용분 = ROUNDDOWN(선납반영 월구독료 × 당월경과일/그달, −2)
③ 선납차감 = −ROUNDUP(선납금 × 잔여비율, −2)
```
> 해지와 달리 위약금 없음(약속 깬 게 아니라 미리 다 냄). 모수는 **케어·보증 제외** 매출인식기준.

### 연체 강제해지
```
연체이자(1회분) = ROUNDDOWN(밀린구독료 × 1.1 × 6% × 연체일수/365, −1)
  · 연체일수 = 다음청구일 − 이번청구일 − 1
  · 1·2·3회분 각각 누적 → 누적 연체이자 = SUM
  · 연체 발생 이후 익월 청구일부터 가산, 비과세

3개월(3회) 초과 → 강제해지 (계약중지일 = 마지막 청구일 + 2일)
정산: 위약금 + 사용분(Σ밀린 미납분 + 당월일할) + 할인회수 + 연체이자 + 선납환불 + 등록비
```
> 중도해지 골격 + **(1) 누적 연체이자 (2) 밀린 미납분 합산** 두 개가 추가됨.
> **MX 차이**: 연체이자 base가 파손 분리 → `(파손제외구독료×1.1 + 파손보험) × 6% × 일수/365`.

## 6. 할인원복 + AS 보상

### 할인원복 (결합이 깨졌을 때)
결합(다품목) 할인은 "여러 개 묶어 산" 조건. 묶음 중 하나(A제품)를 해지하면 조건이 깨짐 → **다품목 할인 회수 + 구독료 정상가 원복**(즉시 아니라 **익익월**부터).
```
· 구독료 원복 = 익익월(예 21회차)부터   ← "출발한 청구 못 멈춰 두 박자 뒤"
· 원복 후 월구독료 = 선납+선납할인만 반영(결합 빠진 값)
· 할인금 회수 = 받은 다품목 할인 × 경과비율
· 원복 후 또 중도해지하면 → 중도해지 5종 골격 그대로
```

### 할인원복 상각표 (= "리스상각표(결합·A해지·월할)" 시트) ★기간 중간 IRR 재계산
A제품 해지로 결합 깨짐 → 남은 제품 월구독료가 정상가로 원복되는 **2단 상각표**:
```
[1단] 할인 구간 (A해지 前): 리스료 = 할인가(예 109,800), 할인 이자율로 상각
[2단] 원복 구간 (A해지 後):
      잔여채권   = 할인구간 해지회차의 기말채권 (그대로 이어받음)
      잔여기간   = N − 해지회차 (+ 부분월)
      원복 이자율 = RATE(잔여기간, −정상리스료, 잔여채권)   ← ★IRR 재계산
      정상 리스료(예 116,000)로 잔여기간 상각 → 만기 0
```
> Level 1 엔진의 "받을 돈 바뀌면 IRR 재계산"이 **계약 중간**에 일어나는 케이스. 리스료가 점프(109,800 → 116,000).

### AS 미사용 기간 보상 (회사→고객 환급)
케어/AS를 약속만큼 못 준 기간 → 고객에게 보상금 환급.
```
미사용기간분 = ROUNDUP(기본 월구독료 × 미사용일/그달일, −2)
```
> **기본구독료 기준(할인 무관)**, 고객에게 주는 돈이라 **ROUNDUP**(고객 유리).
> **MX 차이**: 과세분(÷1.1) + 파손(그대로) 분리 후 합산.

## 7. 회계 종합 (자주 질문)

- **에누리 메커니즘**: 매출인식기준 구독료↓ → 이자수익↓ → **구독기간 전체 스프레드**
- **매출차감(포인트류)**: 당월 손익 즉시 반영
- **할인의 두 얼굴**: 매출차감(포인트류=당월) vs 에누리(선납·단품·결합=기간 스프레드 via 이자수익 감소)
- **100원 내리면?**: 이자수익에서만 빠짐(기간 분산), 제품매출은 cap(MIN)이라 불변. *단, 아주 크게 내려 PV<제품값이면 제품매출도 타격.*
- **이론값 vs 실제값**: 이론=반올림 전 정확값(유효이자율·손익) / 실제=반올림 후 청구·장부값(현금 정산)
- **손익 vs 현금**: 이자수익(손익)=유효이자율(이론) / 중도해지(현금)=실거래액(반올림)
- 단수 반올림차는 immaterial → 순이익 동일, 분류만 다름(이자수익 vs 잡손익)

## 8. 치트시트 (통째 암기)

**정산 비율·방향**
| 정산 | 비율 | 방향 |
|---|---|---|
| 위약금 | 잔여×20% | 고객→회사 |
| 사용분 | 당월경과/그달 | 고객→회사 |
| 할인회수 | **경과** | 고객→회사 |
| 선납환불 | **잔여** | 회사→고객(−) |
| 등록비 | 경과 | 고객→회사 |
| 완납금 | 미사용/전체 | 고객→회사 |
| AS보상 | 미사용일 | 회사→고객(−) |

**과세**: ×1.1 = 구독료·제품·케어·보증·등록비·사용분
**비과세**(v+ 그대로) = 파손보험·위약금·연체이자·분실/파손료

**단수(반올림)**: 구독료·할인 = ROUNDDOWN(−2, 100원) / 위약금·연체 = −1(10원) / 고객환급(AS·선납) = ROUNDUP

**핵심 상수**: 위약율 20% · 연체이자 6%·365일할 · 선납 30% · 할인율(선납4%·단품5%·결합5%) · 청구일 익월15일 · 부가세 v+=v-×1.1

## 11. 용어집 (헷갈리는 것)

- **v- / v+**: 부가세 전(net) / 후(gross). v+ = v- × 1.1 (비과세 항목 제외)
- **혜택가(v-)**: 제품 판매가(할인 전 기준값)
- **매출인식기준 구독료**: 케어·보증 제외한, 회계상 매출로 인식하는 구독료(= 제품 몫)
- **순수구독료**: 총구독료 − 케어 − 보증 (엔진에 들어가는 제품 몫 총액) = 받을총액
- **리스채권**: 회사가 아직 못 받은 제품 원금 잔액
- **리스료**: 매월 회수하는 제품 몫(원금+이자)
- **에누리**: 매출을 깎는 할인(선납·단품·결합) → 이자수익 감소로 기간 분산
- **매출차감**: 포인트류 할인 → 당월 즉시 손익
- **경과/잔여 비율**: Σ경과일/2191 vs (2191−Σ)/2191 (해지정산의 두 축)
- **결합(다품목) 할인**: 여러 제품 묶어 사면 주는 할인 → 하나 해지하면 원복
- **CE / MX**: 가전(에어컨, 72개월) / 모바일(갤럭시탭, 48개월, 파손보험 비과세)

## 12. 시험 직전 30초 점검

1. IRR을 왜 재계산? → 받을 돈 바뀌면 만기 0 위해
2. 할인회수=? 선납환불=? → 경과 / 잔여 (반대)
3. 위약금 과세? → 비과세 v+
4. 완납금 모수? → 매출인식기준(케어·보증 제외)
5. 연체이자? → 6%·365 일할, 회차별 누적
6. 원복 시점? → 익익월
7. 중도해지 현금 기준? → 실거래액(반올림)
8. 에누리가 손익에 퍼지는 이유? → 매출인식기준↓ → 이자수익↓ → 기간분산
9. 이자수익 = ? → **받을총액 − 채권** (제0원리)
10. N개월 면제는 원금? → 아니오, **이자**를 깎는 것 (채권 불변)
