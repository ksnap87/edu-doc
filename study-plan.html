챕터별 외울 것 + 핵심이론

1️⃣ 엔진 — 리스 상각표
이론: 구독=제품 할부판매(금융리스). 리스채권=제품값, 구독료=원금+이자. 받을 돈 바뀌면 내재이자율(IRR) 재계산.
리스채권 = MIN(제품v−, PV(현할차/12, N, −순수월액)) (−선납)
순수구독료 = 총 − 케어 − 보증 (−선납 −할인)
리스료 = 순수/N
월이자율 F3 = RATE(N, −리스료, 채권)  → 연 = ×12
기말 = 기초 + 이자 − 리스료 (만기 0)
첫날/중간/막달 (회사 방식) 
첫날(27/31): 리스료=−(총·케어·보증 각 일할 반올림)=실제청구액
            이자=ROUND(−E + (기초×F3 − H2)×27/31, 0)
중간:        리스료=−H2 / 이자=ROUND(기초×F3, 0)
막달:        리스료=−H2−첫달치 / 이자=plug(잔액 0)
실측: 베이스 4,809,091·15.63% / 선납후 4,065,091·18.17% / 선납+단품+결합 4,065,091·9.91%
2️⃣ 할인 6단계 + 정상청구
이론: 월로 먼저 반올림 후 ×기간(단수조정). 케어·보증 할인 0.
6단계: ①기준×율 ②÷1.1 ③ROUND(②/N,−2) ④×1.1 ⑤③×N ⑥구독료−월할인금
청구일 = EOMONTH(결제월,0)+15 (익월15일)
1회차 일할 = ROUNDDOWN((총/N)×사용일/그달, −2)
제품 = 구독료 − 케어 − 보증
선납금(목돈) ≠ 선납할인(4%). CE↔MX 차이 2개: 파손보험 비과세 / 할인기준=v+−파손.
3️⃣ 중도해지 (정산 5종)
이론: 현금 정산 → 실제 거래액(반올림) 기준.
① 위약금   = 총구독료(v+) × 잔여 × 20% (비과세)
② 사용분   = 반영월구독료 × 당월경과/그달
③ 할인회수 = 받은 할인 × 경과비율
④ 선납환불 = −선납금 × 잔여비율 (회사→고객)
⑤ 등록비   = 등록비 × 경과비율
경과=Σ경과일/2191, 잔여=(2191−Σ)/2191
🧠 할인회수=경과 / 선납환불=잔여 (반대!)
4️⃣ 중도완납 + 연체 강제해지
[완납] 위약금 X
